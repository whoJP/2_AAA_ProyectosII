# Sistema de gestion de biblioteca

## Descripcion
Proyecto academico para organizar el catalogo de libros, registrar usuarios y administrar los prestamos y devoluciones de una biblioteca.

## Objetivo general
Desarrollar un sistema que facilite el control de libros disponibles y prestados, y permita consultar el historial de prestamos de los usuarios.

## Tecnologias utilizadas
- Git y GitHub: control de versiones y revision mediante Pull Requests.
- Visual Studio Code: entorno de trabajo.
- Markdown: documentacion del proyecto.

Tecnologias propuestas para el desarrollo, aun no implementadas: HTML, CSS y JavaScript para la interfaz; Python para la logica del sistema y SQLite para la base de datos.
